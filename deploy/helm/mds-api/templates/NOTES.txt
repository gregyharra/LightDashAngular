1. Get the API service URL inside the cluster:

  kubectl get svc {{ include "mds-api.fullname" . }} -n {{ .Release.Namespace }}

2. Health check (port-forward):

  kubectl port-forward svc/{{ include "mds-api.fullname" . }} 8080:{{ .Values.service.port }} -n {{ .Release.Namespace }}
  curl "http://127.0.0.1:8080/api/v1/health?skipMigrationCheck=true"

3. Ensure DATABASE_URL points at your external Postgres and that pods can reach it.
